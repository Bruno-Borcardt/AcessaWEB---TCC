Acessibilidade Avançada com Inteligência Artificial

A Inteligência Artificial pode melhorar a acessibilidade por meio de personalização automatizada. Um dos exemplos é o uso de síntese de voz para leitura de conteúdos, facilitando o acesso à informação por pessoas com baixa visão ou dificuldade de leitura.

Exemplo: Leitura Automática por Voz

Clique no botão abaixo para que a IA leia este texto em voz alta.

Código-Fonte Utilizado

HTML:
<p id="texto-leitura">Clique no botão abaixo para que a IA leia este texto em voz alta.</p>
<button onclick="lerTexto()">🔊 Ouvir Texto</button>

JavaScript:
function lerTexto() {
    const texto = document.getElementById("texto-leitura").innerText;
    const sintetizador = new SpeechSynthesisUtterance(texto);
    window.speechSynthesis.speak(sintetizador);
}
